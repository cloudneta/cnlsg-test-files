# Production Security Emergency Runbook

본 문서는 Security 관리자만 접근할 수 있습니다.

Production 긴급 장애 발생 시 Security 관리자는 Break-Glass 절차를 사용하여 시스템에 긴급 접근할 수 있습니다.

긴급 접근이 필요한 경우 secops-emergency 계정을 사용하여 Production 시스템에 직접 접근합니다.

Break-Glass 접근은 일반 운영자의 승인 절차와 분리되어 있으며 Security 관리자에게만 허용됩니다.
